# 可信研判工作台前端

Vue 3 + TypeScript + Vite + Vue Flow 证据研判指挥台。所有专题、问题、任务、进度和判断图来自本地 API，没有内置模拟研判结果。

## 启动

要求 Node.js 22.12+ 或 Node.js 24。后端单独运行于 `http://127.0.0.1:8790`。

```powershell
cd web
npm ci
npm run dev
```

打开 `http://127.0.0.1:5190`。Vite 将 `/api` 代理到后端；端口固定，已占用时会明确失败。

```powershell
npm run build
```

构建文件位于 `dist/`。`npm run preview` 仅用于检查构建，生产部署需将 `/api` 转发到后端。

## 当前接入范围

- 本地服务与真实模型配置状态、专题和问题列表。
- 新赛题导入：选择单个 input.json，或原始文档/问题两个 JSON，预检后确认；可下载无答案输入模板。
- 单题或整专题启动研判；超过后端每任务上限时明确提示，绝不静默截取问题。
- 任务控制台：真实已完成阶段数、当前阶段、A/B 独立执行状态、实际已用时间和已记录 token。
- 持久化任务历史，刷新页面或重访专题后自动接管执行中任务；仅把专题偏好保存在浏览器。
- 暂停与继续任务。继续创建有来源关联的新任务；复用后端完成的检查点，旧任务保持原记录。
- 执行观测台：实际工具/模型名称、运行状态、引擎、耗时与安全计数摘要。旧任务未记录的调用不补写。
- 持久化事件游标回放；仅回放执行记录，结果图始终展示通过校验的发布版本。
- Vue Flow 证据星图、结论/独立研判/冲突/质量依据；暗色画布和独立原文抽屉。默认聚焦连接最多的 6 条证据并明确显示证据总数，全部判断与结论保留，可一键展开完整图；只改变视图，不改变引用或导出。
- 证据到原始段落的核查。通过 `Array.from(text)` 按 Unicode code point 切片，并校验 quote 后高亮。
- “如果拿掉这条证据”影响预览，图上高亮下游节点，确认后提交重算；原文只读。
- 固定已发布版本生成导出包，只有导出完成才显示下载链接。

空库和已有资料库均可点击“导入新赛题”。文件格式、答案字段隔离、码点校验和容量限制见根目录 README。也可通过 CLI 导入已准备的原始资料与问题：

```powershell
uv run trust-judge import --directory .runtime/inputs
```

这条命令在项目根目录运行；资料准备方式见根目录 README。参考答案不得进入运行数据库。

模型未配置时禁止启动研判，不使用假结果或静默切换供应商。暂停正在发出的请求不保证撤销供应商计费。模型/流程或资料版本变化导致检查点不兼容时，页面解释原因并提供重新研判。执行中保持任务控制连接，结束或暂停后可以选择历史任务。

未提供人工锁定节点的复核表单、版本差异视图和批量修改。任务观测采用可断线重连的轮询，尚未接入 SSE。动效尊重 `prefers-reduced-motion`；空态星图为装饰，不代表已生成的证据。

`npm test` 覆盖字符位置核查、任务刷新接管、暂停视图状态、多问题阶段完成、计数摘要与未知用量留空等规则。浏览器交互验收单独执行。
